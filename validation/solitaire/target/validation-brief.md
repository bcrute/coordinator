# Klondike validation brief

Create a polished, locally hosted single-player Klondike Solitaire browser app.
It must deal legal games; implement stock, waste, tableau, foundation, moves,
flips, restart, and win detection; provide a responsive mouse/keyboard UI; and
include focused model tests plus a cheap browser or HTTP smoke test. Document
one local start command and all verification commands.

Keep this intentionally small. Do not add accounts, a database, multiplayer,
analytics, payments, or external runtime services.
